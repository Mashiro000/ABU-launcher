# ABU Launcher (阿布桌面)

Kotlin + Jetpack Compose 独立 Android TV 原生工程，不依赖 Flutter。最低 Android 9（API 28）。

## 当前范围

- 新增电影 / 剧集详情页：只保留左侧返回按钮与右侧时间；首屏固定为完整视口，下方内容需滚动后出现。剧集、演职人员与类似作品使用单行横向货架。
- 媒体卡片按点击时的实际边界展开为详情背景（轻微弹簧回弹，阻尼比 0.88、刚度 320，约 0.3% 超调），圆角逐渐过渡到直角；返回用相同弹簧参数收回原卡片。全局 `PageEntranceScope` / `StaggeredEntrance` / `Modifier.staggeredEntrance` 使用共享时间轴：20dp → 0、alpha 0 → 1、380ms、间隔 35ms，缓动为 cubic-bezier(0.16, 1, 0.3, 1)。组件互相重叠，整张卡片一起移动。详情页每次重新打开会入场；回到已有一级页面、刷新与重组不重播，延迟组成的货架也沿用同一时间轴。这是原生 Compose 实现的 Apple TV 风格转场。
- 详情标签位于首屏底部，随首屏一起滚出且不悬浮，点击平滑定位到对应模块。收藏按媒体标题保存在本机；播放、季数、更多菜单为演示交互。音乐、家庭视频及分类卡片仍使用原先占位行为。

- 媒体库首屏：背景、书法标题、继续播放、继续观看横向货架；卡片比例 16:9。
- 首屏固定为一个完整设计视口；我的媒体、我的收藏、最近添加、最近听过、最近的回忆在下滑后显示。
- 所有一级页面共用居中导航和右侧搜索、时间、Wi-Fi、头像。没有品牌和底部角落文字。
- Animeko 默认关闭；点击右上角头像打开设置，开启后显示导航入口及独立占位页。开关保存在本机。
- 其他一级页面为占位；封面、数量、播放进度是展示数据。真实媒体连接与播放未接入。
- Android TV 启动入口、可选系统 HOME 入口、遥控器方向键 / 确认 / 返回、鼠标及触摸。

## 比例与模糊

媒体库共用设计参数：页面左右边距 64，卡片间距 24，模块标题至内容 48，卡片内边距 24；标题 / 卡片名称 / 元信息分别采用 28 / 24 / 20 的设计字号。六列与四列货架按可用宽度计算卡宽，统一左右对齐。海报的封面与说明整体放大，焦点项在同一行置顶；继续观看为焦点缩放预留边缘空间并自动滚动露出完整卡片。

详情页节奏按参考图单独定义（`DetailDesign` 常量）：页面左右边距 72，货架卡片间距 28，模块标题至内容 12，货架上下留白 14，模块间距 32；剧集、演职人员、类似作品的标题与标签不带底板，剧集货架保持单行横向滚动。

界面采用参考图 1672 × 941 设计坐标，按真实可用像素统一缩放，字体缩放固定。16:9 的 720p、1080p、4K 展示比例相同；其他屏幕比例居中等比适配并留边，不拉伸。继续观看仅一行；首屏不会因像素更多而提前显示下一组内容。

Android 13（API 33）及以上使用 Haze 1.7.2 的 `hazeSource` / `hazeEffect`，导航采用真实背景模糊及 `HazeProgressive.verticalGradient`。Android 9–12 使用后台线程计算、缓存的低分辨率壁纸模糊；它模糊静态壁纸，不实时采样滚动媒体货架，也不等同于实时渐进模糊。

媒体库背景随下滑距离连续变暗。Android 13 以上壁纸 Haze 模糊半径从 0 增至 50 设计 dp；兼容路径叠加已渲染的模糊壁纸，透明度从 0% 增至 100%。货架没有独立黑色底板，封面和文字保持清晰。

媒体卡片焦点与鼠标悬停放大 10%。导航下键进入继续观看；左右键横向选择并滚动；卡片下键进入我的媒体，上键返回导航。Esc / 返回关闭弹窗或返回首屏。鼠标滚轮在继续观看区域横向滚动，在其他区域上下滚动。

Haze 文档：https://chrisbanes.github.io/haze/1.5.4/usage/

## 构建

Android Studio 打开本目录。需要 JDK 17 以上、Android SDK 36.1；工程使用 Gradle 9.5.0 / AGP 9.3.2。编译 SDK 的版本不改变最低运行版本 Android 9。

```powershell
./gradlew.bat assembleDebug
```

输出：`app/build/outputs/apk/debug/app-debug.apk`。
