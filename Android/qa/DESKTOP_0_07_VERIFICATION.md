## 视频源与网络边界

审核修订将目录扩展至 114 条，四类分别为海底 21、自然 41、太空 22、城市 30。缩略图全部移出 APK，按每页 8 张联网读取，真实小图资源已准备随最终审核版上传 GitHub，通过 HTTPS 按页加载。

此前把公网下载的 `Trust anchor for certification path not found` 归为隔离环境限制不准确。进一步比对发现 Apple 视频 CDN 使用 Apple Root CA，该根不在 Android 默认信任库中。已从 Apple 官方 PKI 获取公开根证书，使用 Android Network Security Configuration 仅为精确域名 sylvan.apple.com 增加该锚点，继续校验证书链、有效期和主机名，不安装系统证书，也不信任所有证书。

修复后应用宝 Android 12L 直接通过原始 HTTPS 地址完整下载 `asia-night.mov`，文件 214,607,394 字节，视频轨道校验通过，测试耗时 7.531 秒（`OK (1 test)`），未使用本机视频转发；实际下载文件保留供用户设置壁纸。此前的本机转发下载测试仍作为下载流程测试记录，不作为公网连通性依据。

## 适用范围与限制

- 模拟器不能替代低性能电视的真实 GPU 帧率、解码器、厂商 HOME 限制、遥控器连发和待机测试；本次没有虚构真机 FPS 数据。
- 应用宝没有可用的 Android TV 内容频道提供者，真实第三方 Dock 内容效果仍取决于支持的电视固件和应用；无数据时保留壁纸。
- Bing 锁定/恢复逻辑有设备测试；跨真实自然日的持续联网更新未进行 24 小时运行测试。实现为使用桌面期间按日期检查，非强制定时后台唤醒。
- 新版官方模拟器显示现有原生库的 16 KB 页兼容提示，需要系统兼容模式；尚未完成 QuickJS 等依赖的 16 KB 原生库专项迁移。常见旧电视的 4 KB 页场景不受这条提示约束。
- 0.07 使用维护者提供的正式密钥，和旧 0.06 debug 证书不同，不能保证直接覆盖；安装指南明确提示备份/记录配置后自行决定卸载重装，脚本不会自动清数据。
