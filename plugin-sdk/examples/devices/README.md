# 设备清单示例

最低版本：包含宿主 API 1.1 的 ABU APK（0.03 不支持）。源码在 `src/index.ts`；在 `plugin-sdk` 根目录运行 `npm install && npm run build:examples`，生成 `dist/com.example.devices-1.0.0.abu-plugin`。在「设置 → 插件」导入并启用；若设置完整页面被其他插件占用，先停用对方。

进入插件设置页面，选择“刷新 USB 和蓝牙”。分别同意 `usb`、`bluetooth` 插件授权；Android 12+ 还需系统蓝牙连接权限。结果是只读设备清单，设备为空不代表失败。拒绝授权时应显示失败文本。保持页面打开并插拔 USB 或连接/断开已配对蓝牙设备，可以看到 `device.*` 事件提示，按刷新更新清单。没有相应硬件时无法验证广播路径。宿主目前不提供主动扫描、USB 数据通信或蓝牙连接控制，因此这只是掌机模式的能力边界演示，不是完整掌机模式。
