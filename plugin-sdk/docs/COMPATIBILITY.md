# 版本兼容与变更

| 能力 | 已发布 0.03 | 源码中的宿主 API 1.1（待新 APK） |
| --- | --- | --- |
| QuickJS 同步入口、基本 UI、存储、HTTPS、事件 | 有 | 保留 |
| `hostApi` 安装/启用/切换检查 | 无 | 有，范围语法 `>=x.y.z <x.y.z` |
| `list/input/toggle/image/progress` 与插件内导航 | 无 | 有；三星手机触控、遥控确认键、返回和焦点恢复测试通过 |
| 服务发现及真正的 `services.call` | 仅注册/发现 | 可调用；提供方清单声明，启停自动注册/撤销 |
| 完整页面接管 | `home`、`settings` | 同左；`player` 完整页面尚未挂载 |
| 插槽 | 首页和播放器的两个位置 | 同左 |
| 媒体数据源/字幕宿主 API | 无 | `data_source` 列表/分页/播放交接、`subtitle` URL 查询和 Media3/mpv 字幕交接已接入；真实外部字幕源尚待人工验收 |
| USB/蓝牙设备能力 | 拒绝 | 只读 USB 枚举、已配对蓝牙枚举及连接广播；无主动扫描、设备通信 |

`hostApi` 1.1 不会在 0.03 中强制校验：旧 APK 可能安装新包，但运行时会缺少节点/方法。因此开发者须在发布说明中写明最低宿主版本，并让用户先升级。新 SDK 脚手架默认声明 `>=1.1.0 <2.0.0`。旧版无 `hostApi` 的包仍可在新宿主导入，建议作者更新清单。

需要升级现有插件时，请按[从 0.03 迁移到 API 1.1](MIGRATION_0_03_TO_1_1.md)操作；宿主有旧包升级、新包不兼容拒绝和回滚的设备测试。

宿主协议版本与 APK 显示版本不是同一编号。包含 API 1.1 的应用版本标为 `0.04-beta.1`，是开发者预览版；不能把 1.1 能力写成“0.03 已支持”。正式版仍须完成进度文件中的外部验收。破坏性修改应提升 API 主版本、保留旧接口或给出迁移期限。

## SDK 更新记录

- 开发中 / API 1.1：新增清单兼容检查、脚手架、校验器、发布元数据命令、导航和表单节点、声明式服务与服务调用；媒体数据源/字幕入口、只读设备枚举与事件。后台常驻任务、蓝牙主动扫描、USB 设备通信仍不支持。
- 0.03 / API 旧协议：基本 UI、宿主能力、隔离进程和官方库分发；没有可调用的服务 RPC。
