# ABU Launcher 0.06

本版集中处理应用清单刷新、图标错乱和设置操作一致性。

控制中心更新为模块布局，提供模式、信号源与常用功能；设置采用可连续滚动的模块侧栏。完整、精简、无动画均可手动选择，模糊按设备能力降级。

## 应用与桌面

- 安装、卸载和更新应用后重新核对清单，消除旧快照阻挡新应用的情况。
- 图标加载状态按应用身份隔离，列表排序变化不再串用原位置的图标。
- 应用长按菜单从 0% 缩放到 100%，关闭反向收缩，不再淡入淡出；菜单放在图标左右两侧，避开当前图标。
- 恢复此前默认的“跟随内容”壁纸，撤回系统壁纸接入；保留其他已明确选择的壁纸来源。
- 导航条使用均匀背景模糊，取消导航条渐进式模糊。
- 时钟采用等宽数字，显示秒数时保持宽度稳定。

## 设置体验

- “启动与行为 → 开机自启动”提供实体开关。
- 点击面板外开始动画关闭设置，保留原页面状态。
- 遥控器按上下键逐项选择，跨分类滚动不跳项。
- 白色焦点、30% 分类底板、不吸顶的 Dock、收窄的设置列表及对称的左右留白。
- 所有应用自身的设置选择、插件确认、媒体账号配置和更新检查统一在子页面中显示，子页使用左右滑动过渡。
- 插件页分为“插件管理”和“插件商店”，管理启停与权限，商店发现和安装插件。

## 安装包

| 文件 | 适用设备 |
| --- | --- |
| `ABU-Launcher-0.06-arm64-v8a.apk` | 64 位 ARM 手机、电视与盒子 |
| `ABU-Launcher-0.06-armeabi-v7a.apk` | 32 位 ARM 设备 |
| `ABU-Launcher-0.06-x86.apk` | 32 位 x86 设备 |
| `ABU-Launcher-0.06-x86_64.apk` | 64 位 x86 设备与 MuMu |
| `ABU-Launcher-0.06-universal.apk` | 不确定设备架构时使用 |

最低 Android 7.1（API 25）。版本号 0.06，versionCode 8。

## 平台限制

开机自启动仍受厂商的后台启动策略约束，部分系统需放行自启动或设为默认桌面。玻璃效果按系统能力降级。系统安装器、文件选择器与权限授权界面仍由 Android 系统提供。

## 验证

25 项 JVM 单元测试、6 项 MuMu 设置导航测试通过；实测安装卸载刷新、左右菜单避让、设置子页和外部关闭。导航模糊与默认壁纸在追加调整后已复查，Debug 和 Release 构建通过。
