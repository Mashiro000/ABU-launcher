# 电视性能与设置改造（2026-10-12）

## 定位与处理

- 继续观看卡片原先无条件绘制三份模糊封面，并建立离屏纹理；即使低性能模式开启也仍执行。改成单封面与渐变遮罩，降低滑动与焦点缩放时的合成成本。
- 首页原先启动时处理全部应用图像，再发布完整新列表。改为先显示 Dock，应用网格只加载组成的可见行，并限制图像处理并发为两个。
- 首页展开动画原先每帧重新启动 `LaunchedEffect`，条件还直接读取动画进度。改为持续订阅进度，使用派生可见性状态，透明底座颜色在绘制阶段计算。
- 媒体列表转换原先随桌面重组重复执行。现在按实际数据缓存；收藏缓存也按列表内容更新，避免数量相同但内容变化时显示旧结果。
- 桌面插件清单原先在界面组合时反复读取磁盘。现在随页面和设置状态更新缓存。
- 本地演示封面改为后台按需解码。网络海报限制两个加载任务并发，缓存上限改为 32 MiB，按 Bitmap 实际占用计数；使用固定锁池避免长时间浏览产生无限锁记录。

## 用户选择

低性能模式始终提供完整动画、精简动画、无动画三个选项，不按 Android 版本选择。保存用户的明确选择；旧版本已保存的低性能开关迁移为对应选项。

完整动画保留完整过渡。精简动画使用短过渡，并关闭高成本模糊与扫光。无动画使桌面页面、焦点、应用启动、文件夹和设置切换的过渡直接完成。系统 API 版本只用于判断模糊接口是否可用。

## 设置结构

点击控制中心的设置后，从左侧打开 50% 不透明度的黑色面板，宽度为屏幕的 62%。顶栏居中切换应用设置和插件设置，去掉右侧关闭按钮，通过返回键逐级返回并关闭。入口使用正方形大模块，点击模块后收缩为纯图标栏，右侧显示当前模块内容；浅蓝焦点行参考提供的电视设置图片。模块和图标栏使用统一视口、经过视觉尺寸校正的实心矢量图标，控件底板约 95% 不透明度。

背景只使用一个模糊表面：允许实时模糊时，Android 13 及以上在左侧保持 40 dp，右侧最后四分之一从 40 降至 0；Android 12 使用普通实时模糊。静态模糊路径沿用缓存壁纸并按整个桌面的坐标采样，避免窄面板内裁切错位。缺少模糊能力或效果被用户关闭时，保留 50% 黑色层。仍尊重用户保存的低性能模式与模糊开关。

启用路径：应用设置 → 性能与动画 → 低性能模式选择完整动画 → 模糊效果选择实时模糊。支持的系统自动在设置背景启用渐进式模糊，无需单独开关。

应用分类：桌面与外观、启动与行为、应用与文件夹、性能与动画、播放器设置、媒体库设置、系统与关于。

进入任意应用设置模块后，右侧是按上述顺序串联的单个懒加载列表，所有分类可连续向下滚动。滚动位置更新左侧图标高亮；点击图标定位同一列表的对应分类。各分类包含标题和分组底板，遥控器上下键可以直接跨分类，返回二级页面时保留列表位置。滚动同步不会触发分类定位，避免相互反馈导致跳动。

同一分类共用一个圆角底板，使用 30% 不透明度，透出后方背景；分类和组内普通选项均不绘制边框，组内普通选项不绘制独立底板，焦点行只显示浅色高亮。

进入模块后，右侧内容列表宽度缩减 40%，左侧 92dp 图标栏与内容区水平留白保持原尺寸；模块总览仍使用原有宽度。设置行允许标题及当前值占两行，较长文本省略显示并自动增加行高，避免收窄后互相挤压。

“应用与文件夹”新增“应用列表背景模糊”独立开关，默认开启。静态壁纸使用后台生成并缓存的模糊图，展开列表时渐显，避免每帧对整屏实时模糊；视频壁纸继续使用系统支持的实时模糊。模糊强度仍在“桌面与外观 → 玻璃与模糊”调整。全局无模糊或精简/无动画模式会暂停模糊效果，保留用户的独立开关选择。

右侧状态栏去掉所有选项与头像的白色描边，改为靠右自适应排列。“桌面与外观”新增 12/24 小时制、日期显示（公历与农历、仅公历、仅农历、隐藏日期）和时间显示秒数设置。首页、导航条时间与样式预览使用同一时间格式；关闭秒数后首页时钟改为每分钟更新。

导航条右侧搜索单击打开搜索，时间与头像单击打开控制中心，Wi-Fi 单击打开系统网络设置。去掉可点击状态项额外的 focusable 节点，保持单一点击／焦点入口。控制中心在返回键松开时关闭，打开期间禁用背后首页的返回处理，避免一次返回又收起应用列表。关闭不更改当前页面及媒体库滚动位置。

应用 Dock 作为同一 LazyColumn 的普通第一项，与下面应用行共同上下滚动，不再独立吸顶。方向键行索引考虑 Dock 项，返回 Dock 先滚到列表顶部；收起应用列表时重置列表位置。

应用长按菜单的彩色光晕属于背景模糊的色彩渗漏（color bleeding）。菜单现采样桌面实际合成底板（包括应用列表的模糊、渐变与透明遮罩）、时钟、Dock 和应用列表；移除原始壁纸的重复采样。40dp 模糊统一叠加 80% 深色 tint，防止高饱和图标变成强烈亮斑，并去掉外框描边。旧系统或禁用效果时使用同等不透明度底板。

头像快捷菜单改为 420dp 宽的紧凑卡片：大卡片打开设备模式选择，Wi-Fi 和蓝牙打开实际系统设置，信号源列出系统向第三方应用开放的 HDMI 等直通输入，隐藏应用直接进入管理页面。底部提供应用列表、搜索、动画和设置快捷入口，不再显示关机、亮度、音量等原占位项目。设备没有开放信号源时给出说明及设置入口，不显示虚构设备。

设备模式独立保存为主机模式、掌机模式、电视模式，默认电视模式。中央 900 × 228dp 的横向无描边浮层固定按主机、掌机、电视排列；点击后仅改变选中高亮和当前模式文字，不移动卡片、不重置焦点，保持选择框打开。返回和点击框外关闭。底板使用缓存壁纸模糊，视频等场景可使用实时 Haze；全局关闭模糊或精简效果时沿用透明底板降级策略。模式不会切换首页／媒体库或覆盖独立桌面设置；掌机默认触摸交互，主机和电视默认方向键焦点交互，实际触摸／方向键输入仍可自动接管。

信号源使用同一中央横向选择框、模糊底板、面性图标和无描边卡片。系统开放的真实直通信号源按名称与 ID 固定排序，较多输入横向滚动，选择不会调整卡片顺序。“上次选择”仅代表本软件成功打开过该输入，避免冒充系统当前输入状态。没有开放输入时显示说明及信号源设置入口。

菜单动画参考用户提供的完整 7.6 秒视频及点击位置要求：记录头像按下位置，并用菜单在同一根坐标系内的实际边界计算缩放锚点，从该位置展开并收回同一位置；键盘和遥控器使用头像中心。460ms 展开并带轻微回弹，240ms 缩放淡出。默认聚焦左侧第一个“切换模式”，内边距增加到 19dp。只模糊菜单区域，不再对整屏做实时模糊；静态壁纸使用缓存图，减少动画期间重复采样整屏的开销，视频壁纸仍采用支持时的实时模糊。精简动画保留短时渐显，无动画模式立即切换；未自动改变用户的模式选择。

插件页包含管理模块及所有已安装插件模块，每个模块具有图标。插件设置、权限及启停操作在右侧面板内显示。返回可退回模块入口。
