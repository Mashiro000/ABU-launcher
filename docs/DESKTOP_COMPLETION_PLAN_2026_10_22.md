# 阿布桌面完善计划

日期：2026-10-22。状态：已按本计划实施；本次交付与实际验证范围见 `RELEASE_NOTES_0_07.md` 及 `../Android/qa/DESKTOP_0_07_VERIFICATION.md`。下文初步检查保留为实施前记录。

## 目标与边界

优先完成 Android TV 桌面：遥控器操作可靠、低性能电视流畅、保留毛玻璃效果、缩小安装包，并补齐安装和恢复指南。延续阿布现有圆角、玻璃、配色和版式，参考其他项目的交互原则，不直接复制整套界面。

保留普通 APK 点击安装、安装后通过应用图标启动；ADB 和 AI Agent 安装是额外入口。保留 HOME、LAUNCHER、LEANBACK_LAUNCHER 声明。普通运行不依赖 ADB，也不强制成为默认桌面。

当前工作区已有大量未提交修改；实施时在现有工作上逐项核对，保留有效成果，不整体回退。下文“aegris”暂按本次提供的 Aerial/Tigris 移动交互意图理解，具体规则以用户描述为准。

## 分阶段计划与验收

按顺序实施；阶段可单独构建、验收，发现回归先修复再进入下一阶段。

| 阶段 | 优先级 | 工作内容 | 验收条件 |
| --- | --- | --- | --- |
| 0：建立基线 | P0 | 记录当前修改、Release 包体组成、应用列表及设置操作表现；复现抖错图标和空行 | 明确已完成、存在问题、尚未实现三类；保存前后对照数据 |
| 1：应用移动与 Dock | P0 | 修正抖动对象；方向键移动当前应用；Dock 与下面内容分区重排；修复空行；新增添加到 Dock 及满额交换 | 仅当前项抖动；方向键不串区；无中间空洞；移动后焦点跟随；重启保留顺序 |
| 2：设置焦点 | P0 | 单次方向键切换相邻选项；焦点驱动滚动；选中项尽量位于列表中上；正确处理返回和弹窗焦点 | 短按一次只走一项，不变成单纯下滑；长按可控连发；首尾不跳转；滑动可打断 |
| 3：媒体空状态与精简 | P0 | 删除演示数据、占位海报和确认为冗余的资源；无媒体库显示添加按钮并直接进入添加弹窗 | 全新安装不显示假海报；按钮一次进入弹窗；真实媒体加载失败不显示成未添加 |
| 4：低性能优化 | P0 | 静态模糊复用、后台采样、列表按需组合、图标异步加载与缓存、减少每帧布局及无效重组 | 同机同配置比较帧耗时、卡顿、内存；保留模糊；正常浏览无编辑动画常驻 |
| 5：动画节奏 | P1 | 有限时长界面过渡缩短 100ms；文件夹创建统一时间轴、位置和焦点交接 | 文件夹创建无跳帧式接棒、重复图标或消失；快速连续输入可打断；无动画模式仍生效 |
| 6：壁纸与视频壁纸 | P1 | 预览网格、当前选中标记、预览与应用、本地图片与视频、播放策略和失败回退 | 应用后立即生效并保存；离开桌面/待机释放或暂停视频；断网或文件失效有静态回退 |
| 7：导航条自定义 | P1 | 设置项目显示/隐藏、顺序与整条导航栏显隐；长按项目进入移动；提供恢复入口 | 当前项抖动、方向键排序、确认保存、返回取消；隐藏后仍能进设置恢复；重启保留配置 |
| 8：安装与指南 | P1 | 普通 APK、手动 ADB、Agent 三条路径；修正安装/恢复脚本；加入参考致谢 | 普通安装及图标启动正常；ADB 记录真实结果；默认桌面失败如实报告；可恢复原桌面 |
| 9：桌面收尾 | P1 | 文件夹编辑/解散、应用安装卸载后的列表更新、配置迁移、空状态、焦点返回、更新后设置保留 | 按桌面功能清单逐项通过；已知设备限制在文档中明确列出 |

## 应用移动规则

1. 长按应用打开菜单，选择“移动”后仅当前图标轻微抖动；应用身份使用稳定 key，不能依赖变化中的位置索引。
2. 从 Dock 进入移动，默认只在 Dock 内排序；下面应用区同理，不通过方向键意外跨区。
3. 下方网格按上下左右选择目标位置：上下按列数移动，左右按相邻格移动，边界不意外换行或越界。使用插入补位：当前项进入目标位置，中间项目顺移，始终保持紧凑，末行自然留白不算空行。
4. 确认键保存并退出；返回键取消本轮移动、恢复原顺序和焦点。正常浏览不运行抖动。
5. 菜单增加“添加到 Dock”；已在 Dock 内显示适当操作，避免重复加入。同一应用在下方是否继续可见沿用现有产品规则，保持两区数据一致。
6. Dock 未满则加入；已满先展示“选择一个交换 / 取消”。确认目标后一次性完成交换，被换出的应用回到下方合理位置；取消不改任何数据，不静默挤掉已有项。
7. 移动模式与创建文件夹分别进入，避免方向键移到另一图标就意外创建文件夹。文件夹继承稳定身份、保存和取消规则。

## 流畅度和动画策略

- 静态模糊保留现有视觉：后台降采样计算，按背景版本、尺寸和模糊参数缓存。滚动、焦点缩放不重复抓取全屏；壁纸切换或必要的背景变化才更新。
- 导航条、Dock 和弹窗尽量复用模糊来源。视频背景使用低频快照或静态封面作为模糊底图，避免每帧读回视频；实际效果真机确认。
- 审查编辑态普通 Column 一次组合全部图标的开销。优先保持可见区域按需渲染，避免为排序导致整张应用列表重建。
- 图标加载和缩放放到后台，缓存设内存上限，减少主线程包管理器查询；离开桌面停止无关动画与视频工作。
- 页面、弹窗、菜单、文件夹和设置切换先列出当前时长，再各缩短 100ms；700ms → 600ms，460ms → 360ms。已有很短的反馈设置合理下限，避免变成负时长或无反馈。
- 弹簧动画按实际收敛时间校准，关键帧和交错延迟同步调整；不更改长按判定、按键重复阈值、网络超时或视频时长。
- 文件夹创建采用共享进度连接“源图标缩小 → 移动归位 → 文件夹预览接棒”，使用真实测量坐标。中途返回、连续操作及无动画模式都覆盖。
- 设置列表以选项 key 管理焦点；按键推进逻辑焦点后按需滚动，目标约在视口高度 30%–40%，首尾受内容边界约束。不在每次滚动时重复请求焦点。

性能验收在同一电视上对照相同操作，记录帧耗时分位数、卡顿帧比例、冷/热启动及内存峰值；以屏幕刷新率和设备能力为基准，不在尚无真机数据时保证固定帧率。

## 媒体与包体

- 未配置媒体源：仅展示清晰的“添加媒体库”入口；点击直接复用添加媒体库弹窗，取消回到原位置。
- 已配置但为空、正在加载、认证失败、网络异常分别显示真实状态，保留重试和管理入口。缺失封面使用轻量绘制占位，不再打包示例电影图片。
- DemoLibrary/DemoArtwork 混有真实媒体适配类型和图片处理职责，先迁移仍需要的功能，再删除演示代码，避免影响真实媒体详情、背景和搜索。
- 同时分析 Release APK 中图片、字体、DEX、各 ABI 原生库、重复打包依赖；对反射、插件桥和动态资源引用做保留检查，再删除确实未用的项。
- 优先发布适合电视系统 ABI 的安装包，另保留通用包；架构按系统支持识别，不只看芯片型号。主包保留当前基础播放与插件能力，MPV 继续按需提供。
- 构建缓存、临时目录和旧 APK 属于工作区清理项，通常不进入 APK，不能当作安装包缩减收益。未经审计不删除历史产物。
- 输出同版本、同 ABI、同签名配置的压缩前后大小和条目清单，再决定是否有必要进一步拆分资源。

## 壁纸、导航与桌面收尾

壁纸页面沿用阿布视觉，借鉴 Aerial 的预览选择和风景/视频分类方式。提供静态/视频分类、当前壁纸、清晰的应用动作、缩略图和缓存管理；视频默认静音，并提供低性能策略和静态回退。大图与视频按需获取，不内置大体积演示素材。

导航条提供项目显隐、排序和整条显隐。长按可聚焦项目进入排序模式，当前项抖动、其他项补位；横向导航条主要用左右排序，上下不触发意外页面切换。隐藏整条后，保留现有菜单/控制中心的设置入口和恢复默认操作，防止失去导航能力。持久化项目使用稳定 ID，当前页面被隐藏时自动回到仍可用页面。

收尾检查已有功能的闭环：创建/重命名/添加成员/移出成员/解散文件夹；应用安装、卸载、隐藏和恢复；从应用返回桌面；设置和弹窗关闭后的焦点恢复；升级后 Dock、文件夹、导航、壁纸与媒体配置迁移。新增功能按桌面需要补齐，不扩展成无关的大规模功能重写。

## 安装指南交付要求

三个参考的共同点是“能执行本机命令的 Agent + 电视调试授权 + ADB 配置与验收”，不是新的 APK 格式；CleanYourTV 的范围也包含对现有电视环境的配置。

交付内容：

- 更新 README：普通 APK 下载与点击安装优先可见，说明安装后可从应用列表打开，设默认桌面为可选项。
- 修订 docs/ADB_INSTALL.md：包含电脑环境、电视授权、设备识别、ABI 选择、安装、启动、可选默认桌面、权限实际能力、故障排查和恢复。
- 增加给 Agent 的安装说明与可复制提示词；列出具体命令、停止条件和验收输出，不能把脚本退出成功直接当成 HOME 接管成功。
- 审查 install.sh 的包查找、签名冲突、多设备选择、临时文件、失败退出和原桌面记录；文档提到的能力必须在 Manifest/代码中真实存在。
- 当前文档已说明 ConfigReceiver 未实现；Manifest 也未声明文档提到的无障碍桌面守护。先校正文档，再决定必要的兼容实现，不宣传尚不存在的功能。
- 授权、默认桌面和 AOT 分别报告结果；覆盖安装保留数据，不自动卸载解决签名问题。提供实际可用的恢复步骤，不停用原厂桌面。
- 验收普通安装、图标启动、ADB 安装、HOME（系统允许时）、重启/待机唤醒和恢复。无真机验证的品牌写为待验证。

Agent 提示词草案：

> 请先完整阅读 ABU Launcher 的安装指南，帮我把官方 Release APK 安装到电视。电视地址：<IP:端口>。先确认设备和系统 ABI，安装后验证能通过应用图标打开。是否设为默认桌面：<是/否>。需要我在电视上授权时提醒我；保留原厂桌面和恢复入口。完成后给出安装、启动和默认桌面（若选择）的实际验收结果，未实现或受系统限制的步骤如实说明。
