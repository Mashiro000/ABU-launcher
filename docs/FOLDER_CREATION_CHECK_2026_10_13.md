# 创建文件夹动画检查版

参考用户视频 `20261013-1145-32.7660012.mp4`：文件夹底板在原图标背后向外扩张并收稳，原应用缩小移动到左上角预览格。

## 改动

- 控制中心的陡峭曲线用于缩小整张应用卡片时，大部分变化集中在开头，导致完整模式也看起来瞬间缩小。按用户最新要求，创建动画改为 700ms 单调分段：360ms 到 72%，700ms 完成；图标缩小落位与底板展开均不回弹、不超出终点。
- 精简模式使用同样的 700ms 时长，在固定位置交叉渐变原图标与最终文件夹预览，不执行缩小、位移和底板扩张；无动画直接切换。通用动画时长策略不再将精简模式限制为 160ms。
- 控制中心、长按菜单、设置侧栏及子页面、文件夹展开、媒体详情和应用列表的空间过渡在精简模式下改为淡入淡出，设置内补充明确说明。
- 动画直接绘制在桌面覆盖层，取消 Android Dialog 自带的入场动画和全屏变暗。
- 保持源图标焦点尺寸，动画期间隐藏原卡片，避免重复图标或白色焦点叠层。
- 终点按文件夹 24dp 内边距、7dp 间距及实际焦点缩放计算；完成后焦点交接给新文件夹，预览图标使用相同的小圆角。
- 图标运动在布局／绘制阶段读取进度，避免动画每帧重组整个应用列表。
- 文件夹长按菜单直接复用应用图标菜单的实现：相同的侧向避让、缓存／实时背景模糊、圆角、内边距、滑动焦点底色和开关动画。完整模式 0–100% 缩放，精简模式等时长渐变，无动画直接切换；文件夹操作等待菜单退出后执行。
- 最后按用户要求修正未展开文件夹的圆角：由外围 FocusCard 使用与应用图标相同的圆角和默认／G3 设置，移除文件夹底板内层固定圆角的二次裁切。此最后改动仅构建 Release，不再进行测试或模拟器验证。

## 验证与限制

- 最终 Debug、Release 构建成功，39 项 JVM 测试通过。新增测试覆盖完整曲线前 100ms 进度、关键帧、700ms 总时长、全过程单调无过冲，以及精简模式等时长线性渐变。
- MuMu 实例 3 / Android 15 安装最终 Release；分别在完整模式与精简模式创建文件夹、长按打开菜单、返回关闭菜单、重新长按并解散文件夹。UI 树验证操作成功，逐帧检查确认完整模式逐渐缩小无回弹，精简模式固定位置交叉渐变，最终预览没有明显位置跳动；菜单在文件夹侧面显示并使用相同模糊底色和焦点样式。
- MuMu 原系统动画倍率为 0.5，Compose 的实际动画也会加快；临时设置 animator_duration_scale 为 1 后重新录制两种模式，再恢复 0.5。软件的完整／精简时长相同，系统倍率仍受到尊重。录屏为变帧率，不能以平均录制帧率推断设备渲染帧率。
- QA 应用和测试文件夹已移除，模拟器恢复原来的精简动画／静态模糊选择。realme RMX3042 已更新调试包，但停在系统锁屏，本次未完成手机视觉测试。
