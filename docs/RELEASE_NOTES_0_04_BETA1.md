# ABU Launcher 0.04 Beta 1

这是供插件开发者测试宿主 API 1.1 的**预览版**，不是最终的 0.04 正式版。可使用与 0.03 相同的签名证书覆盖升级；升级前仍建议备份重要设置。

## 相比 0.03

- 插件页面支持导航参数、返回与焦点恢复，以及列表、输入、开关、图片和进度节点；触控与遥控器确认键均经过设备测试。
- 支持插件间受控服务调用（含版本约束、启停后的服务注册与撤销）。
- 媒体库接入 `data_source` 插件列表、搜索、分页和播放交接；播放前检查网络权限及 HTTPS 域名白名单。
- `subtitle` 插件可按标题等有限信息返回 WebVTT/SRT 地址，由 Media3 或 mpv 使用；不向插件暴露 Emby Token 或播放请求头。
- 只读 USB 设备清单、已配对蓝牙设备清单及前台连接/断开事件；相关操作需要插件授权，Android 12+ 蓝牙枚举还需要系统权限。
- 新 SDK 提供独立项目脚手架、打包/校验/签名、八个参考插件、迁移指南与按插件 ID 的安全日志命令。官方库目录仍可继续独立更新。

- 0.03 arm64 APK 的 GitHub SHA-256 与发布摘要一致；0.03 与本版的签名证书 SHA-256 均为 `b9f46f3ad4a6027f3384b406ecf07e9e3cef5ddaf8c19e02d732d897dd6d738d`。

## 预览版限制

- 完整播放器页面、后台常驻插件任务、蓝牙主动扫描、USB 数据传输、插件显式取消令牌尚不支持。
- USB/蓝牙真实外设交互及在线字幕的实际播放画面尚未完成设备矩阵验收。
- 仍需一位未参与实现的开发者只按公开文档完成多页面与插件协作/媒体插件，并记录问题；正式版发布前应完成此演练。
- 此版本不预装 MPV。MPV 仍是单独按需安装的播放器插件；默认使用 Android Media3/系统硬件解码。
