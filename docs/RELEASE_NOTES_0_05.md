# ABU Launcher 0.05

## 更新内容

- 重做桌面文件夹展开与收起体验，加入从原图标位置展开的过渡动画、背景模糊和更顺畅的焦点返回。
- 支持向已有文件夹批量添加应用、在文件夹之间移动应用，并在原文件夹仅剩一个应用时自动解散。
- 新增文件夹分页指示器样式，可在“圆点”和“短横条”之间切换。
- 新增启动文件夹内应用后的行为设置，可选择自动关闭文件夹或保持展开状态。
- 优化文件夹分页、排序、遥控器焦点、触控操作和卡片圆角显示。

## 下载说明

| 安装包 | 适用设备 |
| --- | --- |
| `ABU-Launcher-0.05-arm64-v8a.apk` | 64 位 ARM 设备，大多数现代 Android TV 和电视盒子 |
| `ABU-Launcher-0.05-armeabi-v7a.apk` | 32 位 ARM 设备 |
| `ABU-Launcher-0.05-x86.apk` | 32 位 x86 设备和部分模拟器 |
| `ABU-Launcher-0.05-x86_64.apk` | 64 位 x86 设备和模拟器 |
| `ABU-Launcher-0.05-universal.apk` | 不确定设备架构时使用，文件体积较大 |

最低支持 Android 7.1（API 25）。

建议优先安装与设备架构匹配的安装包。覆盖安装前，请确认现有版本与本版本使用相同签名。
