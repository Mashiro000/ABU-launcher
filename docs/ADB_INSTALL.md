# 阿布桌面安装与恢复

支持 Android 7.1 及以上的电视和盒子。可以直接安装 APK，也可以让电脑上的 AI Agent 帮你安装。

## 方式一：直接安装

1. 打开 **[官方下载安装页](https://github.com/Mashiro000/ABU-launcher/releases/latest)**。
2. 展开发布页下方的 **Assets（资源）**，下载 APK。**不知道选哪个，就选文件名带 `universal` 的通用包**；`Source code` 是源码，不能直接安装。
3. 将 APK 复制到 U 盘插入电视，或直接下载到电视。
4. 用电视文件管理器打开 APK，按提示允许当前文件管理器安装应用。
5. 安装完成后选择“打开”，或在电视的“全部应用”中打开“阿布桌面”。

想按 Home 返回阿布：进入阿布 **设置 → 系统与关于 → 设置默认桌面**，按系统提示选择。部分电视没有这个入口，或拒绝第三方默认桌面；仍可通过阿布图标打开。

## 方式二：让 AI Agent 帮你安装

准备电脑和电视，连接同一个网络。使用 Codex、Claude Code、Trae 等**能够在电脑上执行终端命令**的 Agent，普通网页聊天无法直接操作电视。

在电视设置中打开 **ADB 调试 / 网络调试**，并在网络设置中找到 **IP 地址**。不知道开关在哪里时，把电视品牌和型号告诉 Agent。第一次连接会弹出调试授权，在电视上用遥控器允许连接。

### 复制给 AI 的提示词

点击代码块右上角的复制按钮，只需修改电视 IP：

```text
请按 https://github.com/Mashiro000/ABU-launcher/blob/main/docs/AGENT_INSTALL.md 帮我给电视安装阿布桌面，电视 IP 是 192.168.1.20，按 Home 返回阿布；需要我操作电视时提醒我，完成后检查并告诉我怎么恢复。
```

如果只想安装，把“按 Home 返回阿布”改成“只安装，不更换默认桌面”。如果电视显示“无线调试”的配对码和端口，把它们按 Agent 提示提供即可，配对端口与连接端口可能不同。

Agent 会检查电视系统与架构，下载对应官方 APK、安装并检查结果。完成后，用实体遥控器按 Home 确认，再检查待机唤醒是否正常。

## 关于默认桌面与桌面守护

**已发布的 0.07：** 支持 APK / ADB 安装；系统允许时，可设为默认桌面。它不包含新增桌面守护服务。

**新增桌面守护：** 已在本地开发源码中实现，尚未随新版 APK 发布。发布后，需先核实 APK 确实包含服务再授权。守护只观察前台窗口和主页键；通知监听用于系统重新绑定后的恢复，不读取屏幕或通知内容。具体机型仍需实测，不能保证所有厂商固件支持。

安装方式不会自动解决厂商限制。当前发布版设置默认桌面失败时，Agent 应说明原因，并保留普通应用启动方式。

## 恢复原桌面

- 直接安装且未更换默认桌面：无需恢复，从原厂桌面正常使用即可。
- 通过系统设置更换：在系统的默认桌面设置中选回原桌面。
- 让 Agent 安装：把下面一句话发给同一个 Agent：

```text
请帮我恢复这台电视安装阿布之前的原桌面，保留阿布和配置，完成后检查 Home 键是否恢复。
```

使用仓库脚本安装且记录了原桌面的用户，也可以在仓库目录执行：

```bash
TV=192.168.1.20 bash tools/restore.sh
```

## 常见问题

| 遇到的情况 | 怎么处理 |
| --- | --- |
| 不知道下哪个 APK | 选择 universal 通用包 |
| 找不到下载文件 | 展开发布页的 Assets（资源），不要下载 Source code |
| 提示不允许安装 | 按电视提示允许当前文件管理器安装；厂商仍拒绝时，记录型号和错误 |
| 提示与已有应用冲突 | 可能是签名不同。先记录配置，再决定是否卸载旧版；卸载会清除数据 |
| Agent 连不上电视 | 检查同一网络、电视 IP、ADB 开关，以及电视上的调试授权 |
| 按 Home 回到原厂桌面 | 固件可能限制第三方桌面；0.07 不包含新增守护，不能保证接管 |
| 电视找不到阿布图标 | 到全部应用或系统应用管理中找，也可请 Agent 检查安装状态 |

更详细的命令与检查交给 [Agent 安装说明](AGENT_INSTALL.md)。安装思路参考 [CleanYourTV](https://github.com/Gathin23/cleanyourtv) 和 [Aerial](https://github.com/pengchujin/aerial-tv)。
