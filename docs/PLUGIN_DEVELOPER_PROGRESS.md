# 插件开发者平台实施进度

本文件按 [`PLUGIN_DEVELOPER_COMPLETION_PLAN.md`](PLUGIN_DEVELOPER_COMPLETION_PLAN.md) 记录可复核的结果。**尚未完成全部计划，也尚未发布包含宿主 API 1.1 的正式 APK；[0.04 Beta 1](https://github.com/Mashiro000/ABU-launcher/releases/tag/v0.04-beta.1) 已发布，仅用于预览和外部验收。**

| 阶段 | 当前结果 | 尚未完成的验收 |
| --- | --- | --- |
| 1 协议 | `hostApi` 安装/启用/切换检查、脚本包严格清单校验、SDK 类型与 ZIP 畸形包测试；旧版升级/不兼容拒绝/回滚设备测试与迁移指南 | 每个清单字段的完整边界对照仍可加强 |
| 2 宿主 | 参数路由、返回与焦点恢复、UI 节点、服务 RPC、数据源列表/播放、字幕 URL 交接、只读 USB/蓝牙枚举和事件；界面关闭时协程取消不再误报插件错误 | 不提供后台常驻任务/插件显式取消令牌；真实 USB/蓝牙外设和在线字幕播放画面验收；完整播放器页面仍不开放 |
| 3 SDK | 创建脚手架、确定性打包、校验、签名元数据；本地工具测试、ZIP 畸形包和签名负例；Windows/macOS/Linux CI [运行通过](https://github.com/Mashiro000/ABU-launcher/actions/runs/36595688271)；按插件 ID 过滤且只输出安全字段的日志命令 | 自动化安装命令未提供；本地导入仍需用户在 Android 文件选择器操作 |
| 4 文档 | 入门、API、模式、示例、兼容与排障文档；八个可构建示例均有独立 README，覆盖六类场景 | 外部开发者独立演练、更多真实设备场景 |
| 5 发布验收 | Android 单元测试、三星设备 18 项插件安装/运行时/UI 测试（含权限撤销、隔离进程重建、旧版迁移）、R8 正式构建；官方库 CI 下载/哈希/签名核验；0.03 APK 哈希及升级证书连续性已核验；0.04 Beta 预览版四个 ABI APK 上传并核对大小/哈希 | 真实外设/在线字幕播放画面、陌生开发者演练；0.04 正式 APK 发布 |

`data_source`/`subtitle` 和只读 USB/蓝牙能力已在 0.04 Beta 中提供；**0.03 APK 不支持**。完整播放器页面、自动分页控件、后台常驻任务、主动蓝牙扫描及 USB 数据传输仍不可用。发布正式 APK 前要完成外部验收，不能把单元/仪器测试等同于所有真机硬件场景都通过。
