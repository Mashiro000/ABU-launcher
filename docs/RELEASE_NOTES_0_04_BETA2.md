# ABU Launcher 0.04 Beta 2

这是 0.04 系列的测试版。最低支持 Android 7.1（API 25）；可选 MPV 播放器插件要求 Android 8.0（API 26）及以上。

## 更新内容

- 桌面新增应用分组、图标编辑与布局选项；改善应用列表加载、图标与电视横幅缓存。
- 优化遥控器焦点、应用长按菜单及设置页面交互。
- 新增应用内 GitHub 更新检查与更新说明弹窗。
- 改进媒体详情数据缓存、播放器控制层动画及 MPV 播放状态处理。
- 增加 32 位 x86 安装包。

## 下载哪个 APK

| 文件中的架构标识 | 适用设备 |
| --- | --- |
| `arm64-v8a` | 64 位 ARM 设备 |
| `armeabi-v7a` | 32 位 ARM 设备 |
| `x86` | 32 位 x86 设备或模拟器 |
| `x86_64` | 64 位 x86 设备或模拟器 |
| `universal` | 不确定设备架构时使用的通用包 |

这些 APK 为同一版本的不同架构构建，只需安装一个。使用原有签名的用户可覆盖安装；安装前建议备份重要设置。
