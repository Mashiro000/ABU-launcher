# 应用菜单、Dock 滚动与导航修复验证

MuMu 实例 2，Android 12 / API 32。构建 debug、release 和 25 项 JVM 测试通过。

## 实测结果

- 应用长按菜单覆盖首页时钟时，底板正确采样并模糊时钟，没有清晰数字透出。80% 深色 tint 抑制高饱和图标的彩色光晕；外框描边已移除。
- 时间单击打开控制中心、搜索单击打开搜索，已通过实际 UI 检查。
- Wi-Fi 单击进入 `com.android.settings` 已验证；测试没有更改网络连接。
- 媒体库滚动后打开再关闭控制中心，“继续观看”的 bounds 保持 `[73,245][205,287]`，当前媒体库页面没有跳回首页。
- Dock 与应用行共享滚动列表。为让测试应用数量下的内容超出视口，临时设置 MuMu 屏幕为 480 × 1920（应用横屏 1920 × 480）：上滑前 Dock 首卡 bounds 为 `[79,74][358,248]`，上滑后为 `[79,46][358,151]`（部分进入上方裁剪区），回滑后恢复 `[79,74][358,248]`。
- 临时分辨率已恢复为设备原始 1080 × 1920（应用横屏 1920 × 1080）。
- 最终 x86_64 正式包已安装，控制中心打开／关闭通过；测试后的 crash 缓冲区没有异常记录。
